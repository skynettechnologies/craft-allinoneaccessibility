## Installation

**Option 1 – Plugin Store**

1. In the Craft control panel, go to **Plugin Store**.
2. Search for **All in One Accessibility** and install it.

**Option 2 – Composer**

1. Open a terminal in the root folder of your Craft CMS project.
2. Run:

   ```bash
   composer require skynettechnologies/craft-allinoneaccessibility
   ```

3. In the control panel, go to **Settings → Plugins** and click **Install** for All in One Accessibility®.

Package name: `skynettechnologies/craft-allinoneaccessibility`

Check out our [**Craft CMS WCAG accessibility widget installation steps**](https://www.skynettechnologies.com/blog/craft-cms-web-accessibility-widget-installation). Watch the [**Craft CMS installation video guide**](https://www.skynettechnologies.com/all-in-one-accessibility/installation-guide/craft-cms-website-accessibility).

## Configuration

Configure the widget from the Craft CMS admin panel.

**Path:** Settings → Plugins → All in One Accessibility®

**Steps:**

1. Log in to the Craft CMS admin panel.
2. Navigate to Settings → Plugins → All in One Accessibility®.
3. Configure options (color, icon type, position, size).
4. Save your changes

| https://\*.googleapis.com | Google APIs | Services like Fonts, Translation |
| https://\*.gstatic.com | Fonts APIs | Custom Fonts |
| https://vlibras.gov.br | VLibras – Brazilian Sign Language Service | Sign Language |

1. Update your server's CORS configuration to include these URLs.
2. Ensure wildcard subdomains (\*) are supported where necessary.
